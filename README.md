# HTTP 正向代理服务器

这是一个基于 Node.js 开发的 HTTP 正向代理服务器，部署在服务器上后，客户端浏览器通过配置 HTTP 代理，即可使用服务器的 IP 地址进行网络访问。

## 功能特性

- 支持 HTTP 协议代理
- 简单易用，配置灵活
- 支持环境变量配置
- 优雅的错误处理
- 详细的访问日志

## 安装

### 前提条件

- Node.js 12.0.0 或更高版本
- npm 或 yarn 包管理器

### 安装步骤

1. 克隆或下载本项目到服务器

2. 进入项目目录

   ```bash
   cd http-forward-proxy
   ```

3. 安装依赖（本项目仅使用 Node.js 内置模块，无需额外安装依赖）

## 配置

### 环境变量配置

可以通过环境变量来覆盖默认配置：

- `PROXY_PORT` - 代理服务器端口（默认：15007）
- `PROXY_HOST` - 代理服务器主机（默认：0.0.0.0）
- `LOG_LEVEL` - 日志级别（默认：info）

### 示例

```bash
# 设置端口为 3000
PROXY_PORT=3000 node start.js
```

## 启动

### 方法一：直接启动

```bash
node start.js
```

### 方法二：使用 npm 脚本

```bash
npm start
```

### 方法三：使用 PM2 管理（推荐）

```bash
# 安装 PM2
npm install -g pm2

# 启动代理服务器
pm start

# 或者直接使用 PM2
pm start
```

## 使用

### 浏览器配置

#### Chrome 浏览器

1. 打开 Chrome 浏览器
2. 点击右上角的三个点 → 设置 → 高级 → 系统 → 打开您计算机的代理设置
3. 在弹出的网络设置窗口中，找到「代理服务器」部分
4. 勾选「使用代理服务器」
5. 输入服务器的 IP 地址和代理端口（默认为 15007）
6. 点击「确定」保存设置

#### Firefox 浏览器

1. 打开 Firefox 浏览器
2. 点击右上角的三条横线 → 设置 → 常规 → 网络设置
3. 选择「手动配置代理」
4. 在 HTTP 代理中输入服务器的 IP 地址和端口（默认为 15007）
5. 勾选「为所有协议使用相同的代理」
6. 点击「确定」保存设置

### 验证

启动代理服务器后，在浏览器中访问 `http://ipinfo.io`，如果显示的是服务器的 IP 地址，则说明代理配置成功。

## 注意事项

1. **安全考虑**：本代理服务器没有身份验证机制，请确保只在可信网络中使用，或通过防火墙限制访问

2. **性能优化**：对于高流量场景，建议使用 PM2 进行进程管理，并根据服务器配置调整参数

3. **HTTPS 支持**：本代理服务器仅支持 HTTP 协议，不支持 HTTPS 协议的转发

4. **端口开放**：请确保服务器的防火墙已开放代理端口（默认为 8080）

5. **稳定性**：在生产环境中使用时，建议配置监控和自动重启机制

## 常见问题

### 代理服务器无法启动

- 检查端口是否被占用
- 检查是否有足够的权限
- 查看日志输出以获取详细错误信息

### 浏览器无法连接到代理

- 检查服务器 IP 地址是否正确
- 检查代理端口是否正确
- 检查服务器防火墙是否开放了对应端口
- 检查网络连接是否正常

### 代理速度慢

- 检查服务器网络带宽
- 检查目标网站的访问速度
- 考虑使用更强大的服务器

## 技术实现

- 基于 Node.js 内置的 `http` 模块
- 使用 `url` 模块解析请求 URL
- 采用流（Stream）方式处理数据转发
- 实现了优雅的错误处理机制
